# Security Policy

## Supported versions

Only the latest npm release receives security fixes. Users should reproduce a
report against that version or current `main` when practical.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow:

https://github.com/Forest-Isle/Praxis/security/advisories/new

Include affected version, operating system, reproduction steps, impact, and any
suggested fix. Do not include real provider credentials or private transcripts.
You should receive an acknowledgement within 72 hours and a status update
within seven days.

After validation, fixes are developed privately when disclosure would expose
users, then released through the normal attested pipeline. Credit and disclosure
timing are coordinated with the reporter.
