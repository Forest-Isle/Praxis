# Support

Praxis is maintained as an open-source, local-first CLI. Community support is
best effort; no response-time or compatibility SLA is provided.

## Usage questions

Use the [Q&A discussion category](https://github.com/Forest-Isle/Praxis/discussions/categories/q-a)
for installation, provider configuration, workflows, and compatibility
questions. Search existing discussions first and include:

- `praxis --version`, `node --version`, and operating system;
- provider type without credentials;
- the command or workflow being attempted;
- redacted error output and the smallest safe reproduction.

Do not post API keys, private transcripts, proprietary source, or unredacted
debug logs.

## Bugs

Use the [bug report form](https://github.com/Forest-Isle/Praxis/issues/new?template=bug.yml)
for reproducible defects on the latest npm release or current `main`. Questions
and setup problems belong in Discussions so the issue tracker remains
actionable.

## Feature requests

Use the [feature request form](https://github.com/Forest-Isle/Praxis/issues/new?template=feature.yml)
for changes within the single-user CLI boundary. Organization, billing,
enterprise policy, IDE, remote-control, and hosted-service features are outside
project scope.

## Security vulnerabilities

Do not open a public issue or discussion. Follow [SECURITY.md](SECURITY.md) and
use [private vulnerability reporting](https://github.com/Forest-Isle/Praxis/security/advisories/new).
